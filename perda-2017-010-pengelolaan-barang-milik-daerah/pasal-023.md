# Pasal 23
(1) Perencanaan kebutuhan barang milik daerah dilaksanakan setiap tahun setelah rencana kerja OPD ditetapkan.
(2) Perencanaan Kebutuhan sebagaimana dimaksud ayat (1) merupakan salah satu dasar bagi OPD dalam pengusulan penyediaan anggaran untuk kebutuhan baru ( new initiative ) dan angka dasar ( baseline ) serta penyusunan rencana kerja dan anggaran.
